Keyboard shortcuts

Every shortcut the site has, in one place. They work on the home page, in search results and in the reader. Alt shortcuts work even while the cursor is in the search field; on a Mac use Option instead of Alt.

Try them right here

Click inside the reader window below (a real page of the site), then press any shortcut from the tables. The window stays pinned at the top while you scroll; fold it with the arrow when it's in the way.

Try the shortcuts: MN 1 in the readerOpen in a new window

Everywhere​

ShortcutWhat it does
Alt+MOpen / close the menu (burger)
Alt+SQuick settings
Alt+Shift+SFull settings
Alt+P or Alt+YQuick window (compass): favorites, history, key suttas
Alt+HHelp for the current page: search, reader, table of contents
Alt+TLight / dark / auto theme
Alt+− / Alt+= / Alt+0Smaller / larger / normal text size
Alt+1Switch the site language (English / Russian)
Alt+2Table of contents: suttas and Vinaya
Alt+3Dictionary (dict.dhamma.gift)
/Put the cursor into the search field
EscClose the open window, menu or notification
Alt+F, Alt+Shift+F or Ctrl+Shift+FFind on the page
Ctrl+1Home / search
Ctrl+2Table of contents: suttas and Vinaya
Ctrl+3Dictionary (dict.dhamma.gift)

Reading​

ShortcutWhat it does
Ctrl+→ / Ctrl+←Next / previous text
Alt+Shift+1 … Alt+Shift+4Reader modes: Reading, Multi, For Memorization, Devanagari
Alt+ZShow / hide the second language (Pali or translation)
Alt+COne or two columns
Alt+VShow / hide variant readings
Alt+WTable of contents of the text
Alt+LPali script: Latin → Devanagari → Thai
Alt+. or Alt+,Show / hide punctuation in Pali
Alt+QAdd to / remove from favorites
Alt+RRead aloud: start / pause

Search results​

ShortcutWhat it does
Shift+SpaceExpand / collapse all results

Dictionary​

ShortcutWhat it does
Alt+ADictionary on / off
Alt+BDictionary mode
Alt+JMulti-select: look up the selected text automatically
Alt+NOpen the dictionary in a separate window, with the current word

Read-aloud player​

Work while the player is open, without Alt/Ctrl:

KeyWhat it does
SAuto-scroll on / off
1 … 4What to read: Pali · Pali then translation · translation · translation then Pali
− / +Slower / faster
RNormal speed
note

In a text field, Ctrl+←/→ and / keep their usual meaning (moving by words, typing a slash) — only the Alt shortcuts are taken over there.
