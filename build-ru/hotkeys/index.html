Горячие клавиши

Все сочетания клавиш сайта в одном месте. Работают на главной, в результатах поиска и в ридере. Сочетания с Alt срабатывают, даже когда курсор стоит в поле поиска; на Mac вместо Alt — Option.

Попробуйте прямо здесь

Щёлкните внутри окна ридера ниже (это настоящая страница сайта) и нажимайте любые сочетания из таблиц. При прокрутке окно остаётся сверху; если мешает — сверните его стрелкой.

Проба горячих клавиш: MN 1 в ридереОткрыть в новом окне

Везде​

СочетаниеЧто делает
Alt+MОткрыть / закрыть меню (бургер)
Alt+SБыстрые настройки
Alt+Shift+SПолные настройки
Alt+P или Alt+YБыстрое окно (компас): избранное, история, ключевые сутты
Alt+HСправка по текущей странице: поиск, ридер, оглавление
Alt+TСветлая / тёмная / авто тема
Alt+− / Alt+= / Alt+0Мельче / крупнее / обычный размер текста
Alt+1Язык сайта: русский / английский
Alt+2Оглавление: сутты и Виная
Alt+3Словарь (dict.dhamma.gift)
/Поставить курсор в поле поиска
EscЗакрыть открытое окно, меню или оповещение
Alt+F, Alt+Shift+F или Ctrl+Shift+FПоиск по странице
Ctrl+1Главная / поиск
Ctrl+2Оглавление: сутты и Виная
Ctrl+3Словарь (dict.dhamma.gift)

Чтение​

СочетаниеЧто делает
Ctrl+→ / Ctrl+←Следующий / предыдущий текст
Alt+Shift+1 … Alt+Shift+4Режимы ридера: «Читать», «Мульти», «Для запоминания», «Деванагари»
Alt+ZПоказать / скрыть второй язык (пали или перевод)
Alt+CОдна или две колонки
Alt+VПоказать / скрыть варианты чтения
Alt+WОглавление текста
Alt+LПисьмо пали: латиница → деванагари → тайское
Alt+. или Alt+,Показать / скрыть пунктуацию в пали
Alt+QДобавить в избранное / убрать
Alt+RОзвучка: запустить / пауза

Результаты поиска​

СочетаниеЧто делает
Shift+ПробелРаскрыть / свернуть все результаты

Словарь​

СочетаниеЧто делает
Alt+AСловарь вкл / выкл
Alt+BРежим словаря
Alt+JМультивыбор: искать выделенный текст автоматически
Alt+NОткрыть словарь в отдельном окне с текущим словом

Плеер озвучки​

Работают, пока плеер открыт, без Alt/Ctrl:

КлавишаЧто делает
SАвтопрокрутка вкл / выкл
1 … 4Что читать: пали · пали и перевод · перевод · перевод и пали
− / +Медленнее / быстрее
RОбычная скорость
примечание

В текстовом поле Ctrl+←/→ и / работают как обычно (переход по словам, ввод косой черты) — перехватываются только сочетания с Alt.
