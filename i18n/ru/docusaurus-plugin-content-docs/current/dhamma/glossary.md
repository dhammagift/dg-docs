# Глоссарий

Термины, переведённые по [Принципам по Суттам](/sutta), с определениями из Сутт и Винаи там, где они есть. Пали-определение приведено дословно со ссылками на ридер. У части терминов есть и метафоры, которыми их называют Сутты (*adhivacana*, *seyyathāpi*), и их *assāda · ādīnava · nissaraṇa* (привлекательность · недостаток · спасение) словами самих Сутт — для пяти блоков (*khandha*), четырёх *dhātu*, областей (*āyatana*), желания и мира.
