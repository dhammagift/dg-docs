# Быстрое окно (компас)

Быстрый доступ к избранному, истории, ключевым суттам и заучиванию — из
**любого** места сайта, без перехода на другую страницу.

:::tip[Как открыть]
Значок компаса на панели инструментов или в бургер-меню, либо сочетание
клавиш **Alt+P** (или **Alt+Y** — обе версии работают в любой раскладке
клавиатуры).
:::

:::info[Открыть сразу нужную вкладку]
Каждую вкладку можно открыть прямо отсюда, одним кликом:

- <a href="#" onClick={(e) => { e.preventDefault(); window.dgOpenQuickModal && window.dgOpenQuickModal('tab-fav'); }}>☆ + История</a>
- <a href="#" onClick={(e) => { e.preventDefault(); window.dgOpenQuickModal && window.dgOpenQuickModal('tab-4as'); }}>4AS</a>
- <a href="#" onClick={(e) => { e.preventDefault(); window.dgOpenQuickModal && window.dgOpenQuickModal('tab-memo'); }}>Memo</a>
- <a href="#" onClick={(e) => { e.preventDefault(); window.dgOpenQuickModal && window.dgOpenQuickModal('tab-dpd'); }}>Словарь</a>
:::

Сверху, над вкладками — поле поиска: можно искать, не закрывая окно и не
уходя со страницы, где вы сейчас находитесь. Правый клик (или долгое
нажатие на телефоне) по кнопке поиска открывает результаты в новой
вкладке, а не заменяет текущую страницу.

## Вкладки

- **☆ + История** — ваши закладки и история поиска в одном списке.
  Сортировка по алфавиту или по дате (значок ⇅), переименование и удаление
  закладок, скрытие отдельных записей истории. Внизу ссылка **«Вся
  история →»** открывает полную страницу истории.

  :::tip[Значок ⟳ — это ещё и кратчайший путь ко входу в облако]
  Если вы не вошли, клик по значку синхронизации сразу открывает
  [страницу входа](/login) вместо попытки синхронизации — так что это
  заодно самый быстрый способ туда попасть. Правый клик или клик средней
  кнопкой мыши по значку ведут на страницу входа всегда, даже если вы уже
  вошли.
  :::

- **Подписки** — «текст в день». Подпишитесь на собрание (например,
  MN), на поиск или на случайные тексты из выбранных частей канона — и
  получайте по одному тексту в день: по порядку, по числу совпадений (для
  поиска) или случайно. Напоминание приходит раз в день при открытии
  браузера или приложения либо по расписанию (расписание работает в
  приложении). У каждой подписки можно открыть следующий текст, поставить
  её на паузу или изменить. Если вы вошли в аккаунт, подписки и отметки о
  прочитанном синхронизируются с облаком.
- **4AS** — подборка ключевых сутт для изучения Четырёх
  Благородных Истин, шестью тематическими блоками: Четыре Благородные
  Истины (SN 56.11, DN 22, SN 12.2), пять групп цепляния/khandha (SN 22.56,
  22.79, 22.85, вся SN 22), шесть сфер чувств/āyatana (SN 35.228, 229, 236,
  238, вся SN 35), элементы/dhātu (MN 28, MN 115, MN 140, вся SN 14),
  «наслаждение тем, что ведёт к страданию» (SN 14.35, 22.29, 35.19, 35.20)
  и подборка «Extra» из ещё восьми сутт по смежным темам. В конце вкладки —
  карточка **«Вглубь: Hatthipada»**:
  [Hatthipada](https://dhamma.gift/hatthipada/?lang=ru) показывает, как
  сами сутты определяют каждое слово четырёх истин.
- **Memo** — тот же инструмент, что и на отдельной странице
  [Мемо](/memo), встроен вкладкой для быстрого доступа.
- **Словарь** — настоящий [Dict.Dhamma.Gift](https://dict.dhamma.gift)
  вкладкой (с той же темой — светлой/тёмной, — что и у вас сейчас), без
  перехода на другой сайт; подробнее — на отдельной странице
  [Словарь](/dictionary).

На вкладках Memo и «Словарь» значок в верхней панели открывает страницу
вкладки в новом окне.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Alt+P, Alt+Y | Открыть/закрыть быстрое окно |
| Esc | Закрыть |
