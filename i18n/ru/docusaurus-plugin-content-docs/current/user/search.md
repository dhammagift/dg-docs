# Поиск

<img src={SearchLogo} className="dg-page-logo" alt="Значок поиска: лупа с прозрачной зелёной линзой-бриллиантом" style={{width: 84}} />

Поиск по Палийскому канону и переводам — по слову, фразе или регулярному
выражению. Много фильтров и настроек: где искать, на каких языках, сколько
контекста показывать вокруг цитаты, а режим **Слова** даёт отчёт по всем
найденным формам слова. Если точных совпадений нет, поиск находит сутты,
ближайшие по смыслу, — по Суттам и Винае, на пали, английском и русском
([ниже](#основы)). Попробуйте вживую — это настоящая страница поиска:

## Панель инструментов над результатами

<img src={SearchToolbar} alt="Кнопки над таблицей результатов поиска" style={{maxWidth: 'min(700px, 100%)', display: 'block', margin: '0 auto 1.5rem'}} />

- **Saṁvaṭṭo / Vivaṭṭo** — да, подписи буквально на пали («сворачивание» /
  «разворачивание»; на телефоне — значок из двух стрелок) — разворачивает
  или сворачивает цитаты во всех строках таблицы разом (то же самое, что и
  Shift+Space).
- **Слова** — переключает таблицу на список найденных слов вместо списка
  текстов.
- **Варианты чтения** (значок глаза) — показывает или скрывает разночтения
  других изданий. По умолчанию выключено: строки разночтений и совпадения,
  найденные только в них, убираются из результатов и из подсчёта.
- **1/2 колонки** — переключает цитаты между одной широкой колонкой и
  палийский+перевод рядом.
- **Словарь** (значок реплики, Alt+A) — вкл/выкл всплывающий словарь по клику на слово.
- **Мультивыбор** (Alt+J) — выделите несколько слов или целое предложение, и
  они сами откроются в словаре (см. [Словарь](/dictionary)).
- **Компас** — открывает [Быстрое окно](/quickmodal) (избранное, история,
  подписки).
- **Отметки** — добавляет колонку с чекбоксом «прочитано» для каждой
  строки. Это отметки конкретно по текущей выдаче (запрос + область
  поиска), а не по сутте вообще — начав тот же поиск заново, увидите те же
  отметки, но это не то же самое, что общий прогресс чтения сутты.
- **Помощь** — открывает эту же страницу.
- **Подписаться** (значок колокольчика, справа) — присылает найденные тексты
  по одному, как [подписка](/quickmodal); **Настроить →** открывает её
  настройки.

Рядом с числом результатов при необходимости появляется ссылка **«варианты»** —
если у искомого слова есть орфографические варианты написания в текстах,
она ведёт к их списку.

Поиск идёт по тексту Махасангити и по разночтениям, сведённым из других
изданий: тайского (Siam Rath), ланкийского (BJT), бирманского (VRI) и PTS
(**С разночтениями** в быстрых настройках, включено по умолчанию). Слово,
которое в другом издании читается иначе, тоже находится, а с включёнными
**Вариантами чтения** в результате показывается строка Махасангити с
разночтениями к ней.

## Основы

:::info[На каких языках ищет поиск]
Поиск идёт по палийскому корневому тексту и по переводам — обычно
нескольких разных переводчиков на каждый язык (по умолчанию русский и
английский, `langs=ru,en`). Логика зависит от того, каким письмом набран
запрос: кириллица (например, `сострадание`) — поиск идёт только по
русским переводам; латиница или пали с диакритикой (`kacchapa`, `karuṇā`)
— сначала ищется в палийском тексте, и только если там совпадений не
нашлось, поиск повторяется по нерусским переводам (обычно английским).
:::

**Поиск по смыслу.** Когда точный поиск ничего не находит — например,
вопрос своими словами, `почему пять блоков не я`, — показываются сутты,
ближайшие к нему по смыслу, с пометкой *Точных совпадений нет —
предположения по смыслу*. Это предположения: сверяйте найденное по самим
суттам. Охват: четыре никаи, Snp, Ud, Iti и Виная, на пали, английском и
русском. Примеры: [`притча про пилу`](https://dhamma.gift/ru/?q=притча%20про%20пилу) находит MN 21, [`как не бояться смерти`](https://dhamma.gift/ru/?q=как%20не%20бояться%20смерти) —
AN 4.184, [`что ведёт к долгой жизни`](https://dhamma.gift/ru/?q=что%20ведёт%20к%20долгой%20жизни) — AN 5.125.

**Совет #1.** Для поиска на пали можно печатать латинскими буквами без
диакритики (`kacchapa`) — специальные символы (ā ī ū ḍ ḷ ṁ ṇ ṅ ñ ṭ) для
точного запроса вставляют в поле поиска кнопки «Диакритика Pāḷi» в быстрых
настройках, а скопировать их можно из [Памятки по
RegEx](#памятка-по-regex--попробуйте-вживую) ниже.

**Совет #2. Где искать.** По умолчанию поиск идёт по 4 Никаям (ДН, МН, СН,
АН) плюс части Кхуддака Никаи (Дхаммапада, Удана, Итивуттака, Суттанипата,
Тхерагатха, Тхеригатха). Это можно изменить в панели **«Быстрые
настройки»** (кнопка с ползунками рядом с полем поиска) — там же
включается поиск по Винае и выбирается, какие ещё книги Кхуддака Никаи
подключить:

<img src={SearchQuickSettings} alt="Панель «Быстрые настройки» — выбор области поиска" style={{maxWidth: 'min(345px, 100%)', display: 'block', margin: '0 auto 1.5rem'}} />

В той же панели настраивается количество строк контекста до/после цитаты
(«Контекст в цитатах») — тот же параметр, что и кнопки `lb`/`la` в API.

**Совет #3.** Если результатов слишком мало — попробуйте искать по корню
слова, без приставки или окончания.

**Совет #4.** Делайте упор на пали — это язык, на котором записаны самые
древние тексты, связанные с Дхаммой; Будда не говорил ни на русском, ни на
английском.

**Совет #5.** Результаты поиска на пали — это таблица совпадений по
Суттам/Текстам с цитатами и отдельная таблица по словам. Используйте обе.
Для других языков таблица по словам тоже строится, но может работать
менее точно.

**Совет #6.** Минимальная длина запроса — 3 символа, но чем длиннее и
специфичнее шаблон, тем точнее результат.

**Совет #7.** В пали часто есть несколько разных слов там, где в
русском/английском — одно (например, для «змеи»); поиск на пали
раскрывает различия, которые перевод стирает.

**Совет #8.** Если запрос завершается ошибкой из-за таймаута, попробуйте
более длинный или более специфичный шаблон.

:::tip[Быстрый переход по id сутты]
Введите идентификатор сутты (например, `dn22`)
вместо поискового запроса — вместо поиска вы сразу попадёте в ридер на
эту сутту. Работает для ДН, МН, СН, АН, перечисленных книг КН и Винаи.
:::

**Колонка «Mr».** Подсчитывает совпадения по всему тексту (без привязки
к вашему запросу) по шаблону
`seyyathāpi|adhivacan|ūpama|opama|opamma`, игнорируя
`adhivacanasamphass|adhivacanapath|ekarūp|tathārūpa|āmarūpa|\brūpa|evarūpa|\banopam|\battūpa|\bnillopa|opamaññ`.
Нашли другие критерии — создайте issue на GitHub.

## Работа с результатами

- **Клик в конце строки с пали** (курсор меняется со стрелки на палец) —
  перейти в ридер сразу на эту строку.
- **✦** — невидимая ссылка в начале и в конце фрагмента цитаты, чтобы
  открыть текст ридера с нужного места.
- **Нажмите на строку** — появится кнопка воспроизведения, чтобы прослушать
  эту цитату; **Alt+R** читает результаты с первой цитаты, перед цитатами
  каждого текста — его название.
- Поле **Фильтр** над таблицей фильтрует уже показанные результаты. Оно
  понимает написание приблизительно: без диакритики, регистра, придыхания и
  удвоенных букв (`tanha` находит taṇhā, `dama` — dhamma). Кнопка
  **Расширенный фильтр** рядом с ним (значок ползунков) — фильтрация по
  нескольким условиям.
- **Экспорт** — копирование результатов или выгрузка в Excel, CSV, TXT, MD
  (Markdown) или PDF, удобно для ИИ или анализа.
- Кнопка **«Слова»** переключает таблицу на результаты, агрегированные по
  словам, а не по суттам. С шаблоном вроде `kacch.*a` она показывает
  найденные словоформы.
- **Несколько слов.** В быстрых настройках (Alt+S) пункт «Несколько слов»
  выбирает, как искать слова, набранные вместе: **Подряд**, **В абзаце**
  или **По всему тексту** (все слова на любом расстоянии друг от друга).
- **Подборки** на главной — готовые поиски на одну тему; «Показать все»
  открывает их список.
- Под таблицей: **Главная** (главный экран), **История** (история поиска),
  **Читать** (оглавление) и отдельные вспомогательные инструменты —
  **Составить список** (собрать список из произвольного текста), **Сравнить
  списки** (сравнить два списка ссылок) и **Сравнить сутты** (сравнить
  редакции сутты), каждый на своей странице. **Видимость** показывает или
  скрывает колонки таблицы.

## Колонки и ссылки таблицы

- **Sutta** — индекс текста (например, `sn56.11`, `dn22`, `an10.46`).
- **Название** — название текста.
- **Слова** — совпавшие слова в тексте.
- **Кол-во** — количество совпадений в тексте (с выключенными **Вариантами
  чтения** совпадения, найденные только в разночтениях, не считаются).
- **Mr** — сравнения и метафоры в тексте (см. выше).
- **Тип** — `4 Никаи` (Дигха/Мадджхима/Саньютта/Ангуттара), `Кхуддака Никая`
  (все книги КН) или `Виная` (все тексты, относящиеся к Винае). По умолчанию
  скрыта: включается в **Видимости**.
- **Цитата** — цитата с найденным словом, в развёрнутой части строки.
- **Ссылки** — Pi и En открывают текст на s.dhamma.gift (тайское издание, BJT и
  CST с переводами рядом); Ru — русский перевод (Theravada.ru или
  tipitaka.theravada.su, когда доступно). Сам индекс сутты открывает текст в
  ридере Dhamma.Gift.

Аббревиатуры изданий (`ms`, `pts1ed`, `sya-all`, `mr` и т.п.) — смотрите
<SiteLink to="/assets/texts/abbr.html">Edition Abbreviations</SiteLink>.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Alt+A | Вкл/выкл словарь (клик по слову открывает [словарь](/dictionary)) |
| Alt+S | Открыть/закрыть [Быстрые настройки](/settings) (иконка ползунков рядом с полем поиска) |
| Alt+Shift+S | Открыть/закрыть страницу [Настройки](/settings) целиком |
| Alt+T | Тёмная / светлая / авто тема |
| Alt+Space, Alt+Z | Результаты: оба языка → только пали → только перевод |
| Alt+F, Ctrl+Shift+F (на Mac — Cmd+Shift+F) | Найти на странице (работает на всём сайте, не только тут) — есть и в бургер-меню |
| Shift+Space | Свернуть/развернуть все результаты поиска |
| Alt+R | Прочитать результаты вслух |
| / | Поставить курсор в поле поиска |

## Для продвинутых

**Совет #1.** Опция применима только для поиска на пали или английском!
Чтобы найти слово в определённой сутте/самьютте/никае: `Sn17.*seyyathāpi`
выведет все метафоры и сравнения из Sn17. Для нескольких слов в кавычках:
`"Sn51.*(seyyathāpi|adhivacan|ūpama|opama)"`.

**Совет #2.** Для вариаций используйте `[]`: `nand[iī]` найдёт и `nandi`, и
`nandī`.

**Совет #3.** Чтобы найти слово, начинающееся/заканчивающееся определённым
шаблоном, используйте `\b`: `\bkummo\b` найдёт только `kummo`, пропустив
`kummova` и другие совпадения.

**Совет #4.** Поддерживаются полноценные регулярные выражения GNU
`grep -E` (с корректным экранированием). ИИ может сгенерировать шаблон —
подсказки и ссылки есть в [Памятке по RegEx](#памятка-по-regex--попробуйте-вживую) ниже.

**Совет #5.** Результаты выводятся с помощью
[DataTables](https://datatables.net/).

**Совет #6. Подборки.** В кавычках можно собрать произвольную подборку:
`"sn42.8|sn20.5"` выведет обе сутты полностью в одну таблицу; `"Sn20.1"`
выведет Sn20.1, Sn20.10, Sn20.11 и т.д.; `"Sn20.1\b"` — только Sn20.1.
