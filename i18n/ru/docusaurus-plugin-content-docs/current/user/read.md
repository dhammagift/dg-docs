## Режимы чтения

Четыре режима чтения (панель «Режимы чтения» в бургер-меню ☰, каждый со
своим хоткеем Alt+Shift):

<img src={ReaderModesDrawer} alt="Панель «Режимы чтения» в бургер-меню" style={{maxWidth: 'min(320px, 100%)', display: 'block', margin: '0 auto 1.5rem'}} />

| Хоткей | Режим | Что показывает |
|---|---|---|
| Alt+Shift+1 | Читать | Pāḷi + перевод, всегда на основном языке |
| Alt+Shift+2 | Мульти | Pāḷi + сохранённый набор языков и переводчиков рядом |
| Alt+Shift+3 | Для запоминания | Мнемоника по первой букве (тот же приём, что в [Мемо](/memo#сжать--подсказки-по-первой-букве), но сразу на живом тексте сутты) |
| Alt+Shift+4 | Деванагари | Pāḷi в другом письме + Pāḷi латиницей |

:::tip[Alt+Shift+цифра — режим, Alt+1 — язык]
Alt+Shift+1…4 переключают режим и оставляют язык, на котором вы читаете.
Язык переключает **Alt+1** — одинаково на всех страницах сайта; **Alt+2**
открывает оглавление, **Alt+3** — словарь.
:::

Режим не привязан к конкретному языку жёстко — «Деванагари», например,
показывает пали в ЛЮБОЙ выбранной системе письма рядом с латиницей (см.
ниже), а не только деванагари как таковую.

Переводы есть на 25 языках. Для тайского первым идёт Mahachula (DN 1–34,
MN 1–76), затем Siam Rath.

## Контекстное меню

Главная «жемчужина» ридера — контекстное меню на каждой строке текста.
Наведите курсор на начало или конец строки (пали или перевода) — появится
маленькая **✦**; клик по ней открывает меню сразу с 7 действиями:

<img src={ReaderContextMenu} alt="Контекстное меню сегмента: Строку, Абзац, Ссылка, Слушать, Избранное, Медитировать, Сравнить" style={{maxWidth: 'min(460px, 100%)', display: 'block', margin: '0 auto 1.5rem'}} />

- **Строку** — скопировать эту строку (пали + перевод) со ссылкой на неё.
- **Абзац** — скопировать все строки от этой и до конца абзаца (для
  стихов/гатх, где нет общего абзаца — только текущая строка).
- **Ссылка** — скопировать только ссылку на строку, без текста.
- **Слушать** — начать голосовое озвучивание с этой строки — см.
  [Голос / TTS](/tts).
- **Избранное** — добавить строку в закладки — см. вкладку «Избранное» в
  [быстром окне](/quickmodal).
- **Запомнить** (иногда подписано «Медитировать» — оба открывают одно и то
  же, подпись выбирается случайно) — открывает
  [Запоминание](/memo) с текстом от этой строки и дальше (примерно до
  1200 знаков).
- **Сравнить** — открывает эту строку в 4nt со всеми изданиями пали
  параллельно (MS, королевское, мьянманское, BJT).

:::info[Почему клик по самому тексту делает что-то другое]
Меню открывается только с невидимой **✦**. Клик по самому тексту строки
(не по ✦) выделяет её для голосового плеера и показывает кнопку ▶
Play — это отдельная функция, подробнее в [Голос / TTS](/tts).
:::

**Правый клик / долгое нажатие на ✦** — короткий путь: сразу копирует
ссылку на строку, без открытия меню.

## Система письма пали

Кнопка **Alt+L** циклически переключает четыре распространённых системы:
ISO-латиница → брахми → деванагари → тайское письмо. Полный список — около 160
систем письма (бирманская, кхмерская, сингальская и т.д. — всё, что умеет
конвертировать Aksharamukha) — доступен в выпадающем списке на странице
[Настройки](/settings).

## Размер текста

В бургер-меню (☰) есть кнопки **−** и **+**: размер текста от 70 % до
250 %. То же делают **Alt+−** и **Alt+=**, а **Alt+0** возвращает 100 %.

## Словарь

Клик по любому слову пали (при включённом словаре) сразу ищет его в
[Dict.Dhamma.Gift](/dictionary) — либо во всплывающем окне поверх текста,
либо в отдельной вкладке, в зависимости от выбранного режима словаря.
Подробнее о самом словаре, его горячих клавишах и режимах отображения —
на странице [Словарь](/dictionary).

Сам режим словаря (какое именно окно открывать) и ещё пара настроек
чтения — в панели **«Быстрые настройки»** (значок с ползунками рядом с
полем поиска, работает и внутри ридера):

<img src={ReaderQuickSettingsDict} alt="Панель «Быстрые настройки» в ридере: режим словаря и опции чтения" style={{maxWidth: 'min(300px, 100%)', display: 'block', margin: '0 auto 1.5rem'}} />

- **Словарь** — тот же список режимов, что описан на странице
  [Словарь](/dictionary): встроенный DPD, попап или новое окно Dict.DG
  (обычное/мини), DharmaMitra.org, только поиск по суттам, либо внешние
  приложения (DPD Android, DictTango, Mdict, GoldenDict-NG) — раздельно для DPD на
  английском и на русском.
- **Варианты чтения** (Alt+V) и **Режим колонок** (Alt+C) — те же кнопки,
  что и в тулбаре над текстом, продублированные здесь для удобства.
- **Скрыть пунктуацию Pāḷi** (Alt+G) — убирает знаки препинания из
  палийского текста, удобно для заучивания наизусть.

Ниже в той же панели — блок **«Диакритика Pāḷi»**: набор кнопок с
палийскими спецсимволами (ā ī ū ṁ ñ ṅ ṭ ḍ ṇ ḷ) — клик вставляет символ
прямо в поле поиска в позицию курсора, если их нет на вашей клавиатуре.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Alt+Shift+1 … Alt+Shift+4 | Переключить режим чтения (см. таблицу выше) |
| Alt+1 | Переключить язык (русский / английский) |
| Alt+C | Переключить 1-колоночный / 2-колоночный вид |
| Alt+V | Показать/скрыть орфографические варианты пали |
| Alt+Q | Добавить/убрать текущую страницу из избранного |
| Alt+A | Вкл/выкл [словарь](/dictionary) по клику на слово |
| Alt+N | Открыть [словарь](/dictionary) в отдельном окне |
| Alt+W | Оглавление текста |
| Alt+2 | Открыть [Навигатор TOC](/toc) на главе этой сутты |
| Alt+Z | Показать/скрыть пали или перевод (кнопка Pāḷi / Рус внизу справа) |
| Alt+− / Alt+= / Alt+0 | Мельче / крупнее / обычный размер текста |
| Ctrl+← / Ctrl+→ | Предыдущая / следующая сутта |
| Клик по строке | Выделить для голосового плеера (см. [Голос / TTS](/tts)) |
| Клик по ✦ в начале/конце строки | Открыть контекстное меню (см. выше) |
| Правый клик / долгое нажатие на ✦ | Скопировать только ссылку |

Все горячие клавиши — на странице [Горячие клавиши](/hotkeys).

## Внешние издания и перекрёстные ссылки

Панель под названием текста ведёт на другие издания и ресурсы того же
отрывка:

- **Voice** — встроенный TTS-плеер (Alt+R).
- **4nt** (s.dhamma.gift) — параллельное сравнение изданий пали.
- **DPR** — Digital Pali Reader, мьянманское и тайское письмо.
- **Tpt.lk** — Буддха Джаянти Типитака на tipitaka.lk.
- **SC** — SuttaCentral.net.
- **TBW** — TheBuddhasWords.net.
- **Th.ru / Th.su** — Theravada.ru / Theravada.su (только в русском интерфейсе).
- **Final** (только у текстов Винаи) — переход к финальной редакции
  правила, если оно менялось по ходу истории/обсуждения.

Правее в этой же строке — иконки: показать/скрыть варианты (см. Alt+V
выше), 1/2 колонки, [словарь](/dictionary), мультивыбор для словаря, компас
и «Помощь» (ведёт на эту страницу). Значок оглавления (Alt+2) открывает
[оглавление](/toc) сразу на главе этой сутты. Если текст входит в одну из
ваших подписок, в панели появляется колокольчик (см. вкладку «Подписки» в
[быстром окне](/quickmodal)).

## Под текстом

- **Слушать в MP3** — под некоторыми текстами есть строка с MP3 всего
  текста: пали и перевод, с именем переводчика.
- Под каждым текстом — ссылки **Принципы по Суттам · Обоснование ·
  Глоссарий**.
- Ряд значков: копировать ссылку, экспорт (сохраняет сутту в PDF или
  Markdown), «Редактировать перевод» ([Редактор переводов](/translator)),
  [Memo](/memo), Create Lists, сравнение, DharmaMitra и 4nt.
- Кнопка **Pāḷi / Рус** внизу справа (Alt+Z) показывает или скрывает
  любой из двух языков.
