# Настройки

Настоящая, живая страница настроек — ничего нажимать или искать на
клавиатуре не нужно:

<AppFrame src="/settings/" title="Живая страница настроек" height={700} />

## Быстрые настройки — отдельная панель прямо у поля поиска

Кроме этой полной страницы есть вторая, лёгкая панель — **«Быстрые
настройки»**, значок с ползунками рядом с полем поиска (⚙︎-иконка слева
от лупы), также открывается сочетанием **Alt+S**. Она не дублирует страницу настроек, а даёт быстрый доступ к
самому нужному прямо там, где вы сейчас работаете — на главной, в
результатах поиска или в ридере, без перехода на отдельную страницу.
Набор групп меняется в зависимости от того, где вы находитесь — вот все
группы, которые в ней встречаются:

<img src={QuickSettingsFull} alt="Панель «Быстрые настройки» на странице результатов поиска — все группы сразу" style={{maxWidth: 'min(340px, 100%)', display: 'block', margin: '0 auto 1.5rem'}} />

- **Где искать** — те же 4 Никаи / Кхуддака Никая / Виная, что и «Где
  искать по умолчанию» ниже на этой странице, но меняет область поиска
  только для текущего запроса.
- **Словарь** — какой режим словаря использовать (см. [Словарь](/dictionary)).
- **Контекст в цитатах** — только на странице результатов: сколько строк
  показывать до/после найденной.
- **Вид выдачи** — Тексты / Слова (только на странице результатов).
- **Чтение** — Варианты чтения и Режим колонок (в ридере), Скрыть
  пунктуацию Pāḷi (везде, где есть текст на пали).
- **Скрипт для Деванагари** — появляется только когда ридер в режиме
  «Деванагари» (см. [Ридер](/read)).
- **Несколько слов** — как искать слова, набранные вместе: Подряд, В
  абзаце или По всему тексту (см. [Поиск](/search-guide)).
- **Диакритика Pāḷi** — кнопки со спецсимволами пали (ā ī ū ṁ ñ ṅ ṭ ḍ ṇ ḷ),
  клик вставляет символ прямо в поле поиска.

Изменения в «Быстрых настройках» сохраняются сразу — это те же
настройки, что и на полной странице ниже, просто под рукой, без перехода
никуда.

## Общее

- **Язык интерфейса** — меню и подписи (не влияет на языки текстов).
- **Тема** — светлая / тёмная / авто. **Alt+T**. (Хранится в
  `localStorage.theme` — том же ключе, которым для своего переключателя
  темы пользуется и этот сайт справки, поэтому переключение здесь или на
  этой странице держит обе темы синхронизированными «на лету», в рамках
  одного origin.)
- **Облако** — синхронизация закладок, заметок и настроек между
  устройствами, см. [Вход](/login).
- **Описания кнопок** — короткая строка под названием каждой кнопки на
  главной; если выключить, описание остаётся только всплывающей
  подсказкой.

## Чтение

- **Языки для чтения** — не только русский и английский: 25 языков с
  числом доступных текстов у каждого. Первый
  выбранный — основной, от количества языков зависит режим отображения
  в ридере (см. [Режимы чтения](/read#режимы-чтения)); порядок можно
  менять перетаскиванием чипов.

  <img src={SettingsLanguages} alt="Выбор языков для чтения — далеко не только русский и английский" style={{maxWidth: 'min(460px, 100%)', display: 'block', margin: '0 auto 1.5rem'}} />

- **Система письма пали** — ISO-латиница и другие системы письма (см.
  [Систему письма пали](/read#система-письма-пали) в статье про Ридер).
  Переключатель **Только в режиме «Деванагари»** решает, применяется ли
  выбор везде или только в режиме ридера «Деванагари».
- **Размер текста** — плюс/минус, от 70 % до 250 %, тот же **Alt+=** /
  **Alt+-**, что и везде на сайте (**Alt+0** возвращает 100 %).
- **Показывать пунктуацию в пали** — выключите, чтобы убрать
  запятые/кавычки и заменить точки/`?`/`!` вертикальной чертой — ближе к
  виду рукописей. **Alt+G**

## Поиск

- **Где искать по умолчанию** — тот же чекбокс-список 4 Никаи / Кхуддака
  Никая / Виная, что и в «Быстрых настройках», но здесь — какое значение
  использовать по умолчанию для новых запросов (в самом поиске область
  по-прежнему можно поменять для одного конкретного запроса).
- **Языки для поиска** — по умолчанию совпадают с языками для чтения;
  переключатель позволяет задать для поиска отдельный набор языков.
- **Строк контекста** — сколько строк показывать до/после совпадения
  (числом, не кнопками — та же настройка, что «Контекст в цитатах» в
  Быстрых настройках).
- **Несколько слов — в любом порядке** — уже видна в интерфейсе, но
  честно помечена как «пока не реализовано на сервере» — переключатель
  недоступен.

## Словарь

- **Dict.DG** — общий выключатель словарной платформы (см.
  [Словарь](/dictionary)).
- **Режим** — какое конкретно окно/вкладка открывается по клику на слово.
- **En / Ru** — язык значений в словаре.
- **Искать выделенный текст автоматически** — то же самое, что кнопка
  мультивыбора в ридере (**Alt+J**): выделили несколько слов — словарь
  ищет их сам, без клика по кнопке. Есть настройка задержки (3 или 5 сек).

## Коренной текст пали

В результатах показывается текст **Mahāsaṅgīti** (MS), а разночтения — по
всем изданиям (BJT, VRI, Сиам, PTS); поиск идёт и по ним. Выбрать BJT, VRI,
SIAM или PTS как текст в ридере можно будет скоро.

## Озвучка

- **Ключ Google Cloud API** — необязательно: голоса Google работают со
  встроенным пробным ключом, свой ключ — для постоянного пользования
  (хранится только в этом браузере) — подробности в [Голос / TTS](/tts).
- **Голос и скорость чтения** — открывает отдельную панель (ту же, что
  значок настроек в самом плеере ридера, Alt+R) — см. [Голос / TTS](/tts).

## Данные

- **Офлайн-библиотека** — скачать всю библиотеку на это устройство, чтобы
  поиск и чтение работали без интернета; «Удалить» освобождает место. В
  приватном окне (инкогнито) не работает.
- **История поиска и избранное** — «Очистить» стирает их с этого
  устройства (хранятся локально, если вы не вошли в [облако](/login)).
- **Все настройки** — «Сбросить» возвращает всё на этой странице к
  значениям по умолчанию, не трогая историю, избранное и вход в облако.

## Связанные горячие клавиши

| Клавиша | Действие |
|---|---|
| Alt+S | Открыть/закрыть Быстрые настройки (значок с ползунками рядом с поиском) |
| Alt+Shift+S | Открыть/закрыть эту страницу настроек целиком |
| Ctrl+Shift+F (на Mac — Cmd+Shift+F) | Найти на странице — не Alt+F, это [избранное](/read); и не просто Ctrl+F, его перехватывает собственная поисковая панель браузера |
| Alt+Z | Показать/скрыть второй язык |
| Alt+T | Тема |
| Alt+G | Убрать пунктуацию пали |
| Alt+J | Мультивыбор для словаря |
| Alt+= / Alt+- | Размер текста |
| Ctrl+1 / Ctrl+2 / Ctrl+3 | Главная / Оглавление / Словарь |
| Alt+1 | Язык сайта |
| Alt+8 | Режим отображения ml/th |
