# Dhamma.Gift (приложение)

Android-приложение: тот же сайт, но полностью офлайн — все тексты, переводы
и словарь хранятся на самом устройстве (кроме принципиально онлайн-функций
вроде голосов Google или внешних словарей — они и на сайте работают только
при подключении к интернету). Те же ярлыки и «Поделиться, чтобы найти», что
и на самом сайте, подробнее описано на странице
[«PWA: установка прямо из браузера»](/pwa).

**Скачать:** последняя сборка лежит на GitHub —
[релизы dg-app-full](https://github.com/dhammagift/dg-app-full/releases/latest)
(файл `app-debug.apk`). Android спросит подтверждение: приложение ставится
не из Google Play. Тексты скачиваются при первом запуске, в APK их нет.

Эта же ссылка — за кнопкой «Download Android APK» на главной странице
сайта.
