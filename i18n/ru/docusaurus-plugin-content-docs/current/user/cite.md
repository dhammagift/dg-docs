# Как цитировать

## Датасет

Перевод проекта, пали сегмент за сегментом, глоссарий с местами, где сутты определяют каждый термин, и тексты
«Принципы по суттам» и «Обоснование» опубликованы как датасет на
[Zenodo](https://doi.org/10.5281/zenodo.23491473), [Hugging Face](https://huggingface.co/datasets/dhammagift/dg-dataset)
и [GitHub](https://github.com/dhammagift/dg-dataset).

> Dhamma.Gift. *Dhamma.Gift: the Suttas read by the Suttas' own definitions* [dataset]. Zenodo, 2026.
> https://doi.org/10.5281/zenodo.23491473

Этот DOI всегда открывает последний выпуск. Чтобы сослаться на тот выпуск, которым вы пользовались, добавьте его
версию и возьмите DOI этого выпуска на странице Zenodo (раздел «Versions»).

BibTeX:

```bibtex
@dataset{dhammagift_dataset,
  author    = {{Dhamma.Gift}},
  title     = {Dhamma.Gift: the Suttas read by the Suttas' own definitions},
  publisher = {Zenodo},
  year      = {2026},
  doi       = {10.5281/zenodo.23491473},
  url       = {https://doi.org/10.5281/zenodo.23491473}
}
```

На GitHub кнопка **Cite this repository** даёт то же в APA и BibTeX.

## Строка сутты

У каждой строки каждого текста постоянная ссылка: номер текста и номер строки. В ридере её копирует меню строки
**✦** → **Ссылка** (см. [Чтение](/read)).

> Dhamma.Gift. SN 56.11:4.2, русский перевод. https://dhamma.gift/sn56.11:4.2?lang=ru (дата обращения: 14.11.2026).

Цитируя пали, называйте издание: по умолчанию Махасангити (MS), или то, что выбрано в ридере (BJT, CS, SR, MS 2005, PTS).

## Термин глоссария

У каждого термина свой якорь: слово на пали после `#`.

> Dhamma.Gift. «dukkha». *Глоссарий*. https://dhamma.gift/ru/docs/glossary/#dukkha
