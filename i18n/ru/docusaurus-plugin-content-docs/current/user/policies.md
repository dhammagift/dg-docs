# Политика конфиденциальности и условия использования

## Конфиденциальность

Мы придерживаемся принципа **максимальной анонимности**. Проект
спроектирован так, чтобы использование функций поиска и чтения не требовало
раскрытия личности пользователя.

### Облачная синхронизация (опционально)

Эта функция включается на сайте и/или в PWA, Android- или iOS-приложении
Dhamma.gift **только по желанию пользователя** для сохранения истории,
избранного, прогресса чтения, подписок и настроек между устройствами.

- **Инфраструктура** — данные хранятся во внешней облачной базе данных
  **Google Firebase**.
- **Методы входа**:
  - *Анонимный вход* — при использовании секретной фразы она хэшируется на
    вашем устройстве (SHA-256) перед отправкой. В базе хранится только
    анонимный идентификатор, исходная фраза не сохраняется.
  - *Google-аккаунт* — используется только ваш email для идентификации
    сессии. В базе хранится хэшированная запись, скрывающая ваш email.
  - *Вход с Apple* — так же, как с Google: мы получаем ваш идентификатор
    пользователя Apple и email, который передаёт Apple (если выбрано «Скрыть
    e-mail», это анонимный адрес для пересылки, созданный Apple), и
    используем их только для идентификации сессии.
- **Хранение данных** — сохраняются только ваши закладки (Favorites),
  история поиска, прогресс чтения текстов, подписки «Ежедневного чтения» с отметками о прочитанном и настройки интерфейса. Эти данные доступны исключительно
  вам после авторизации.
- **Удаление** — вы можете в любой момент полностью удалить все свои данные
  из облачной базы через кнопку «Удалить аккаунт и данные» в меню синхронизации.

### Обрабатываемые данные

Продукты обрабатывают только минимальные технические данные, необходимые
для основной функциональности:

- **Поиск** — передаются только поисковые запросы, ссылки на тексты или
  выбранные слова для словаря.
- **Синхронизация** — при использовании функции синхронизации обрабатываются
  метаданные об активных сессиях (тип ОС и браузера) для управления вашими
  устройствами.
- **Календарь упосатхи (Ariyuposatha)** — место, которым вы делитесь (с округлением до
  километра), и ваши настройки остаются на вашем устройстве и нам не передаются;
  время солнца и луны считается на устройстве, напоминания ставятся на самом
  устройстве.
- **Технические данные** — базовая метаинформация запросов (IP-адрес,
  User-Agent), собираемая веб-серверами для защиты от атак.

### Что мы НЕ собираем

- Личную информацию пользователей (за исключением email при входе через
  Google или Apple).
- ID пользователей Telegram или истории чатов.
- Историю посещений вне наших сервисов.
- Постоянные идентификаторы для отслеживания (вне рамок выбранной
  пользователем сессии синхронизации).

### Передача данных

Наши собственные сервисы:

- <SiteLink to="/">dhamma.gift</SiteLink> / [dict.dhamma.gift](https://dict.dhamma.gift/)
  — для поиска и чтения.
- **Google Firebase** — исключительно для обеспечения работы функции
  облачной синхронизации и только если вы вошли в аккаунт.

Один внешний сервис:

- [dpdict.net](https://dpdict.net/) — Digital Pāḷi Dictionary, для тех
  словарных статей, которых нет в нашем встроенном словаре. Передаётся
  только само палийское слово, без аккаунта, идентификаторов и любого
  другого контекста. Часть таких запросов делает наш сервер, часть — прямо
  ваш браузер или приложение; во втором случае dpdict.net видит ещё и ваш
  IP-адрес, как любой сайт, который вы открываете. Это их сервис и их
  политика конфиденциальности, не наша.

Данные пользователей не передаются третьим сторонам для маркетинговых или
иных целей.

### Хранение данных

- **Без синхронизации** — мы не храним поисковые запросы, слова или
  историю на серверах; все данные хранятся только локально в
  `localStorage` вашего браузера.
- **При синхронизации** — данные (история, избранное, прогресс чтения, подписки, настройки) хранятся
  в облачной базе Google до тех пор, пока пользователь не решит их удалить.
- **Офлайн-библиотека** — полная база текстов (около 200 МБ загрузки, около
  590 МБ на устройстве) скачивается с dhamma.gift и хранится только на вашем
  устройстве. На сайте и в PWA загрузка начинается только по вашему
  согласию. В приложениях для Android и iOS при подключении к Wi-Fi загрузка
  начинается автоматически, её можно отменить; при мобильном интернете
  приложение сначала спросит разрешение. База содержит только тексты и не
  содержит данных о вас. В офлайн-режиме поиск и чтение текстов выполняются
  на устройстве, без запросов к нашему серверу. Обновления базы предлагаются
  не чаще раза в две недели. Удалить базу можно кнопкой «Удалить» в
  настройках офлайн-библиотеки.
- **Логи** — технические логи серверов хранятся максимум 30 дней.

## Условия использования

Два разных случая, и разница существенна.

### Общественное достояние — SuttaCentral

Все материалы проекта [SuttaCentral](https://suttacentral.net/) (данные
Bilara) — палийские тексты, традиционные комментарии и переводы — переданы в
общественное достояние по лицензии
[CC0](https://creativecommons.org/public-domain/cc0/). Их можно свободно
использовать, копировать и перерабатывать, в том числе коммерчески, без
чьего-либо разрешения.

### Всё остальное — бесплатно и только для некоммерческого использования

Материалы, созданные проектом Dhamma.gift, распространяются по лицензии
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/deed.ru).

Остальные тексты публикуются здесь с разрешения их авторов и издателей,
**бесплатно и только для некоммерческого использования**; права на них
остаются за правообладателями:

- английские переводы **Тханиссаро Бхиккху** — см.
  [dhammatalks.org](https://www.dhammatalks.org/);
- русские переводы **А. Я. Сыркина**, **В. Н. Топорова** и других
  переводчиков, указанных при каждом тексте;
- отредактированные проектом версии этих русских переводов;
- материалы **[TheBuddhasWords.net](https://thebuddhaswords.net/)**.

Для любого использования за пределами бесплатного личного чтения обращайтесь
к правообладателям. Сайт и приложения Dhamma.gift бесплатны, и Dhamma.gift не
добавляет ограничений сверх тех, что уже несёт исходный материал.
