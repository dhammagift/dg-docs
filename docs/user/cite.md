# How to Cite

## The dataset

The project's translation, the Pali segment by segment, the glossary with the places where the Suttas define each
term, and the texts Principles by Suttas and Rationale are published as a dataset on
[Zenodo](https://doi.org/10.5281/zenodo.23491473), [Hugging Face](https://huggingface.co/datasets/dhammagift/dg-dataset)
and [GitHub](https://github.com/dhammagift/dg-dataset).

> Dhamma.Gift. *Dhamma.Gift: the Suttas read by the Suttas' own definitions* [dataset]. Zenodo, 2026.
> https://doi.org/10.5281/zenodo.23491473

This DOI always opens the newest release. To cite the exact release you used, add its version and take that release's
own DOI from the Zenodo page (under "Versions").

BibTeX:

```bibtex
@dataset{dhammagift_dataset,
  author    = {{Dhamma.Gift}},
  title     = {Dhamma.Gift: the Suttas read by the Suttas' own definitions},
  publisher = {Zenodo},
  year      = {2026},
  doi       = {10.5281/zenodo.23491473},
  url       = {https://doi.org/10.5281/zenodo.23491473}
}
```

On GitHub, **Cite this repository** gives the same in APA and BibTeX.

## A sutta line

Every line of every text has a permanent link: the text's id and the line's number. In the reader the line's
**✦** menu → **Link** copies it (see [Reading](/read)).

- **Chicago (note):** Dhamma.Gift, SN 56.11:4.2, Russian translation, https://dhamma.gift/sn56.11:4.2?lang=ru (accessed November 14, 2026).
- **MLA:** "SN 56.11:4.2." *Dhamma.Gift*, dhamma.gift/sn56.11:4.2?lang=ru. Accessed 14 Nov. 2026.
- **APA:** Dhamma.Gift. (n.d.). *SN 56.11:4.2* [Russian translation]. Retrieved November 14, 2026, from https://dhamma.gift/sn56.11:4.2?lang=ru

Name the Pali edition when you quote the Pali: the Mahāsaṅgīti (MS) by default, or the one picked in the reader
(BJT, CS, SR, MS 2005, PTS).

## A glossary term

Each term has its own anchor: the Pali word after `#`.

> Dhamma.Gift. "dukkha." *Glossary*. https://dhamma.gift/docs/glossary/#dukkha
